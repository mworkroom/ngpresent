# NANGOK 교육자료 캡처

애터미 상품 상세에서 필요한 세로 구간만 골라 JPG로 저장하는 Chrome 확장 프로그램입니다.
HTML로 만든 상세 설명과 긴 이미지형 상세 설명을 같은 방식으로 캡처합니다.

## 처음 설치

Chrome 116 이상에서 사용할 수 있습니다.

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 저장소의 `extension` 폴더를 선택합니다.
5. 퍼즐 모양 확장 프로그램 메뉴에서 **NANGOK 교육자료 캡처**를 고정합니다.
6. 상품 페이지 새로고침은 확장 프로그램이 자동으로 처리합니다.

## 사용하는 순서

1. 애터미 상품 페이지를 엽니다.
2. 애터미 상품 페이지에서 고정해 둔 **NANGOK 교육자료 캡처** 아이콘을 누릅니다.
3. 처음 한 번은 바탕화면의 `교육 자료` 폴더를 선택합니다.
   - 폴더가 없다면 선택 창에서 새로 만듭니다.
   - Chrome 보안 규칙 때문에 확장 프로그램이 바탕화면 폴더를 몰래 정할 수 없어 이 선택만 한 번 필요합니다.
4. 새 폴더 이름을 정확히 씁니다. 비워 두면 **상품 페이지 새로고침하고 시작**을 누를 수 없습니다.
   - 예: `마이크로바이옴 KR`
5. **상품 페이지 새로고침하고 시작**을 누릅니다.
   - 프로젝트 폴더를 만듭니다.
   - 애터미 상품 페이지를 자동으로 새로고침합니다.
   - 페이지와 확장 프로그램의 연결이 끝나면 2단계가 나타납니다.
6. 제품사진을 저장합니다.
   - 옆 패널의 **제품사진 저장하기**를 누릅니다.
   - 자동으로 이동한 페이지 위쪽에서 큰 제품사진을 한 번 누릅니다.
   - 원본 사진이 `제품사진.jpg` 또는 `제품사진.png`로 바로 저장됩니다.
   - 제품사진이 더 있으면 **제품사진 한 장 더 저장하기**를 반복합니다.
   - 모두 저장했으면 **제품사진 저장 완료 → 다음 단계**를 누릅니다.
7. 상세 설명 그림을 저장합니다.
   - 상품 페이지에서 저장할 그림의 맨 위를 누릅니다.
   - 아래로 내려가 그림의 맨 아래를 누릅니다.
   - 옆 패널의 번호 저장 버튼을 누릅니다.
   - 저장이 끝나면 같은 위치에서 바로 다음 번호의 맨 위를 고르는 상태로 이어집니다.

## 저장 규칙

- 기본 위치: `바탕화면\교육 자료\사용자가 입력한 폴더명`
- 일반 그림: `1.jpg`, `2.jpg`, `3.jpg` 순서
- 한 번 고른 범위는 길어도 한 장의 JPG로 저장
- **제품사진 저장하기**: 원본이 JPG면 `제품사진.jpg`, PNG면 `제품사진.png`
- 제품사진은 필요한 만큼 반복 저장한 뒤 사용자가 완료 버튼을 눌러 본문 작업으로 이동
- 이미 같은 번호가 있으면 그다음 번호부터 이어서 저장
- 기존 제품사진이 있으면 확장자와 관계없이 `제품사진-2.jpg` 또는 `제품사진-2.png`처럼 저장하여 덮어쓰지 않음
- 브라우저가 한 장으로 만들 수 없는 극단적인 크기일 때만 범위를 나누어 선택하라는 안내를 표시
