# 2026-08-02 ngpresent 개발 로그

## 작업 요약

nghome의 AI 가이드 페이지에서 사용하던 하단 네비게이션 버튼을 ngpresent 첫 화면에도 추가했습니다. 교육자료를 만드는 현재 화면에서 AI 안내 페이지와 PDF 안내 페이지로 바로 이동할 수 있습니다.

## 완료한 작업

- `index.html` 하단에 이전 단계와 다음 단계 링크를 추가했습니다.
- 이전 단계는 `https://www.nangok.app/guides/ai.html`로 연결했습니다.
- 다음 단계는 `https://www.nangok.app/guides/pdf.html`로 연결했습니다.
- `style.css`에 nghome의 흰색 이전 버튼과 파란색 다음 버튼 모양, 아이콘, 호버 효과를 적용했습니다.
- 작은 화면에서는 두 버튼이 세로로 배치되도록 반응형 규칙을 추가했습니다.

## 결정 사항

- 참조 페이지의 `.bottom-actions`, `.back-link`, `.next-step-link` 구조를 그대로 사용해 사이트 간 이동 경험을 통일했습니다.
- 현재 화면의 주요 기능을 방해하지 않도록 네비게이션은 작업 카드 아래에 배치했습니다.
- 사용자가 다음 행동을 쉽게 알아볼 수 있도록 버튼 문구를 `이전 단계: AI로 그림 만들기`, `다음 단계: PDF로 합치기`로 작성했습니다.

## 현재 상태

- HTML과 CSS 변경을 완료했습니다.
- `git diff --check`를 통과했습니다.
- 데스크톱 화면에서 버튼의 흰색·파란색 스타일과 좌우 배치를 확인했습니다.
- 390px 화면에서 두 버튼이 세로로 배치되고 같은 너비를 사용하는 것을 확인했습니다.
- 다음 단계 버튼을 눌러 `https://www.nangok.app/guides/pdf.html`로 이동하는 것을 확인했습니다.
- 콘솔 오류와 경고는 확인되지 않았습니다.

## 다음 단계

- 배포 전 변경사항을 J님이 확인합니다.

## 작업 요약 - 하단 네비게이션 버튼 높이 통일

하단 네비게이션의 이전·다음 버튼 높이가 화면 방향에 따라 달라지는 문제를 수정했습니다.

## 완료한 작업 - 하단 네비게이션 버튼 높이 통일

- 저장 완료 패널 전용 `.next-step-link` 스타일을 `.next-step-panel .next-step-link`으로 범위 제한했습니다.
- 하단 네비게이션의 두 버튼에 `min-height: 52px`를 동일하게 적용했습니다.
- 데스크톱 Flex의 자동 늘어남에 의존하지 않고 모바일에서도 버튼 높이가 같도록 수정했습니다.

## 결정 사항 - 하단 네비게이션 버튼 높이 통일

- 같은 클래스 이름을 유지하되 저장 완료 패널과 하단 네비게이션의 스타일 적용 범위를 분리했습니다. 기존 저장 완료 패널의 큰 버튼 디자인은 유지하면서 하단 버튼만 별도로 통제할 수 있기 때문입니다.
- 버튼 높이는 참조 페이지의 다음 버튼 기준인 52px로 통일했습니다.

## 현재 상태 - 하단 네비게이션 버튼 높이 통일

- `git diff --check`를 통과했습니다.
- 데스크톱과 390px 모바일 화면에서 하단 이전·다음 버튼의 실제 계산 높이가 모두 `52px`임을 확인했습니다.
- 저장 완료 패널의 전용 버튼은 기존 `74px` 높이를 유지하는 것을 확인했습니다.
- 다음 단계 버튼을 눌러 PDF 안내 페이지로 이동하는 것을 확인했습니다.
- 콘솔 오류와 경고는 확인되지 않았습니다.
